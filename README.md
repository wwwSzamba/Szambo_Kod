#iwanan.gg

Strona internetowa, na której możesz sprawdzić, czy jesteś lepszy w League of Legends od Tomasza **"iwanana" Gaś**. Aplikacja korzysta z publicznego Riot Games API, aby porównać Twoje statystyki rankingowe ze statystykami "bossa" w czasie rzeczywistym.

#Opis

iwanan.gg to wielostronicowa aplikacja front-endowa (HTML/CSS/JS), która pozwala wyszukać gracza League of Legends po Riot ID (`Nazwa#TAG`) i porównać jego statystyki rankingowe z danymi gracza-bossa. Serwis pobiera dane bezpośrednio z Riot Games API i prezentuje je w przejrzysty, kartowy sposób.

#Funkcjonalności

- Strona główna (`index.html`)** — wyszukiwanie gracza i porównanie 1v1 z bossem (ranga, winrate, KDA, CS/min), z algorytmem oceniającym kaskadowo, kto jest lepszy.
- Bohaterowie (`bohaterowie.html`)** — statystyki najczęściej granych bohaterów wyszukanego gracza na podstawie ostatnich meczów (winrate, pick rate, liczba gier).
- Rankingi (`rankingi.html`)** — globalny rozkład rang (wykresy słupkowy i kołowy) z podziałem na regiony oraz lista na żywo najlepszych graczy (Challenger) z możliwością doładowywania kolejnych wpisów.
- JJK Spoiler Toggle** — przełącznik zmieniający obrazki na stronie głównej (easter egg związany z Jujutsu Kaisen).
